Prepare your document for review.

Identifiers are checked locally first; population counts use the selected source. Only the prepared text can be sent to a review model, and only after the privacy gate passes.

Count matches against the configured local synthetic reference.

  1. LocalRead the PDF and replace names, emails, phone numbers, student IDs and course sections with tokens.
  2. PopulationEstimate how many people in a reference population match each described participant.
  3. LocalApply suggested rewrites until no participant is above the high-risk threshold.
  4. ModelSend the prepared text for rubric review, if a model is configured. Format rules run locally either way.

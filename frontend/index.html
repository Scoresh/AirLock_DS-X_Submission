Prepare your document for review.

Identifiers and re-identification risk are checked on this machine first. Only the prepared text can be sent to a review model, and only after the privacy gate passes.

  1. LocalRead the PDF and replace names, emails, phone numbers, student IDs and course sections with tokens.
  2. LocalEstimate how many people in a reference population match each described participant.
  3. LocalApply suggested rewrites until no participant is above the high-risk threshold.
  4. ModelSend the prepared text for rubric review, if a model is configured. Format rules run locally either way.

Working with a data table instead?

Upload a CSV. Identifier columns become tokens, identifying columns are generalized, and you get the re-identification risk before and after. Everything runs on this machine.

# Replace the parse stub with real PDF parsing

**Files changed:**
- `backend/app/parse.py`
- `backend/app/main.py` (unreadable uploads return 400)

`/parse` now reads the uploaded PDF locally with PyMuPDF instead of returning the mock pages. For each page it extracts the text, the margins (distance from the page edges to the outermost text block), every font name and size with character counts, and the printed page number with its position (for example bottom-center or top-right). The page number is left out of the text and the margin measurement. A plain UTF-8 .txt upload also works (pages split on form feeds), and the UI's placeholder upload falls back to `samples/test-thesis.pdf`, so the demo runs without picking a file. Anything else returns a 400 error. On the test thesis it reports the planted 0.75 in left margin on page 3, the page number moving to top-right, and the switch to Helvetica 11 on page 4. The full flow on the uploaded PDF finds all four participants, tokenizes the name, email and phone, opens the gate at k 74/69/32/20, and the margin rule flags page 3.

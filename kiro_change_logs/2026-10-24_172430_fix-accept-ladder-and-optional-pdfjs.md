# Fix step-2 gate: iterate "Accept all" up the generalization ladder; make PDF.js optional

**Files changed:**
- frontend/app.js

The uploaded PDF's data was reaching step 2 correctly (verified: `POST /parse` -> `/scrub` -> `/score` all return the real participants and suggestions, and a headless browser showed 4 participant cards rendering), but "Accept all suggestions" left the gate closed so it looked like nothing happened. Root cause: generalization is a ladder (e.g. `country22` -> `countrycol22` -> `internat`) and each `/score` only offers the NEXT step per field, so one pass of Accept wasn't enough to clear high-risk participants — a second, deeper suggestion only appears after the first is accepted. Rewrote the `#accept` handler to loop: it keeps resending the currently-offered fixes (the backend accumulates accepted fixes across calls and ignores inapplicable ones) until the gate opens, no suggestions remain, or the offered set stops changing (progress guard, capped at 12 rounds). Verified server-side that this converges in 3 rounds with the sample doc and opens the gate (all participants reach low risk), and confirmed in a headless Edge session that a single Accept click now enables Send and shows "Gate open." Separately hardened PDF.js: replaced the top-level static CDN `import` (which, if it failed offline, silently prevented every event handler from being attached — a plausible "upload does nothing" cause) with a lazy, non-fatal dynamic import, so the core pipeline works even without network and the canvas heatmap degrades to blank pages. No backend code changed.

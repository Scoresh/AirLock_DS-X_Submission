# Add a Render blueprint for the hosted demo

**Files changed:**
- `render.yaml` (new), `backend/scripts/make_render_data.py` (new), `backend/app/risk.py`

Added a Render blueprint that installs the backend and the spaCy model and starts uvicorn on Render's port with Python 3.13. The organizers' data stays out of git: `make_render_data.py` writes a 1 MB copy with only the six columns the risk engine reads, which is added in Render as the secret file `NSSE-synthetic.csv`; `risk.py` reads the path from `NSSE_DATA_FILE` when it is set. Tested the exact start command locally with that file: setup reports ready and the demo thesis gives the same results.

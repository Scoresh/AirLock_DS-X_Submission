# Audit OpenAI + Gemini LLM contracts; trim Claude model presets

**Files changed:**
- `backend/app/settings.py`

Audited the ChatGPT (OpenAI) and Google Gemini configurations end to end without launching the server, using localhost stub servers to capture exactly what the client sends. Confirmed for every preset model (OpenAI: gpt-4o-mini/gpt-4o/gpt-4.1-mini/gpt-4.1; Gemini: gemini-1.5-flash/1.5-pro/2.0-flash) that `settings.apply` resolves the correct base URL (`https://api.openai.com/v1` and `https://generativelanguage.googleapis.com/v1beta/openai`), sets `LLM_API_STYLE=openai`, and that the client POSTs to `/chat/completions` with `Authorization: Bearer <key>` (no `x-api-key`), `temperature: 0`, `response_format: {"type":"json_object"}`, and system+user messages, then parses `choices[0].message.content`. Also verified that every real prompt sent through `chat_json` (rubric parse, rubric check, settings test) contains the word "JSON", which OpenAI's `json_object` mode requires. Separately, in response to repeated Anthropic 404s (`claude-3-opus-latest`, then `claude-3-opus-20240229`), trimmed the Claude preset to broadly-available aliases (`claude-3-5-haiku-latest`, `claude-3-5-sonnet-latest`, `claude-3-haiku-20240307`), set the default to Haiku (most widely enabled), and documented that account/tier-specific models can be entered via the UI's "Other…" free-text option. No OpenAI/Gemini code or presets needed changes; they were already correct.

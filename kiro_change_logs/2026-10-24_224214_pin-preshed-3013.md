# Pin preshed 3.0.13 outside Windows

**Files changed:**
- `backend/requirements.txt`

The hosted demo failed to load the spaCy model with "OverflowError: Python int too large to convert to C ssize_t". A fresh Python 3.13 environment with preshed 3.0.14 (the newest release) reproduces the error on macOS; swapping to 3.0.13 in the same environment loads the model. Fresh installs on Linux and macOS now get preshed 3.0.13; Windows keeps the 3.0.9 pin.

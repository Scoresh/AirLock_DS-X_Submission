# Integrate JIFF into the document Privacy Check

**Files changed:** `backend/app/{main,population_check,risk,schemas,scrub,store}.py`, `backend/scripts/run_jiff_demo.py`, `frontend/{app.js,index.html,styles.css}`, `jiff/`, `tests/test_population_integration.py`, `mock/score.json`, `README.md`, `docs/JIFF_INTEGRATION.md`.

Added an explicit per-document JIFF population source while preserving default local pandas behavior. Researcher-side profile extraction now uses a public codebook without loading private population records. Added an authenticated localhost bridge, relay job coordination and an independent Registrar process for batched real MPC counts. Bound scores to document state, accepted rewrites and the population manifest, with expiry, per-document locking and fail-closed checks on both review endpoints. Updated the frontend for source selection, source/version display, invalidation and retry states, and a matching fictional sample PDF. Fixed successful JIFF disconnects to flush pending shares and added an independent-process regression test. Added a one-command synthetic demo launcher, a real HTTP end-to-end self-test and documentation of assumptions and scale limits. Updated the additive score contract and its mock example, with Python and Node tests covering compatibility and authorization behavior.
